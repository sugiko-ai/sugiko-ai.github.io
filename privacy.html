プライバシーポリシー

内容確認日：2026年11月11日

本方針は、利用者本人1人がWindows PCで使用する「AI業務管制室」と、この公開説明サイトに適用します。アプリは不特定多数に提供していません。

1. Googleアカウント情報の利用目的

Googleカレンダーの本人の予定をアプリで確認するため、Google公式OAuth 2.0を使用します。許可された範囲でAPIへアクセスするための認証情報を利用します。Googleアカウントのパスワードはアプリで取得・保存しません。

現在の連携は、カレンダー一覧と予定の閲覧を目的としています。Gmail本文、Googleドライブのファイル、連絡先、Googleのプロフィール情報を取得する権限は要求していません。カレンダーIDには、Googleアカウントのメールアドレスを含む場合があります。

2. 取得する情報とアクセス範囲

  • カレンダー一覧：ID、名称、主カレンダーかどうか、アクセス権限の種類。
  • 選択したカレンダーの予定：予定ID、件名、説明、場所、開始・終了日時、更新情報、予定の状態、繰り返し情報など、表示と差分取得に必要な情報。
  • 認証と同期の管理情報：OAuthトークン、クライアント設定、同期用ID・差分トークン、最終同期日時、同期の成功・失敗履歴。

現在使用するGoogle権限は、calendar.events.readonly（予定の閲覧）とcalendar.calendarlist.readonly（カレンダー一覧の閲覧）です。これらのGoogle権限自体は複数のカレンダーを閲覧できる範囲を持ちますが、アプリの予定取得対象は設定で選択したカレンダーです。

現在の日常用は閲覧専用です。
Googleへの予定登録・編集・削除は行いません。

将来、双方向同期を日常用で有効化する場合は、変更前に本方針と画面の説明を更新し、本人の明示承認・Google公式画面での必要な同意を受けます。送信対象は指定した予定情報に限定し、TODO、案件、事故・苦情、報告、資料を無条件に送信しません。現在の方針は、将来の書き込みを許可するものではありません。

3. 認証情報・予定データの保存

認証情報とGoogleから取得した予定のキャッシュは、利用者のPC上で、Windowsの本人用保護機能（DPAPI）により暗号化して保存します。アプリ内で入力した業務記録、変更履歴、資料は、PC上のデータベースやファイルとして保存します。業務データ全体をアプリが一律に暗号化しているわけではありません。

障害や誤操作に備えて、PC上にバックアップを作成します。認証状態の過去の暗号化ファイルや、過去の業務記録・資料がバックアップに残る場合があります。保存期限による自動的な一括消去は行っていません。

4. 外部送信・第三者提供

現在のGoogle連携では、OAuth認証・更新・連携解除と、カレンダー一覧・予定の取得のためにGoogleと通信します。必要な認証情報、対象カレンダーの識別情報、取得条件等をGoogleへ送ります。通信にはHTTPSを使用します。

アプリのGoogle連携機能は、取得したGoogleユーザーデータを広告配信、販売、第三者のAIモデルの学習、外部の分析サービスへの提供に使用しません。Google連携に必要な通信を除き、業務記録や取得した予定を第三者へ自動転送する機能は今回の連携に含めていません。利用者が自ら出力・共有するファイルや、別途設定したPCの同期・バックアップサービスは、その利用者の操作・設定に従います。

Google APIから受け取った情報の使用・他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

5. 連携解除とデータ削除

  1. アプリの「保存・保護」からGoogleカレンダーの「連携解除」を実行すると、自動取得を停止し、現在の接続用トークンをアプリの有効な接続状態から外します。
  2. アプリはGoogleへのトークン失効要求も行います。通信等でGoogle側の解除が完了しなかった場合は画面に案内します。Googleアカウントの接続管理画面からもアプリへのアクセス権を取り消せます。
  3. 連携解除だけでは、取得済みの予定、業務記録、変更履歴、資料、バックアップは消えません。Google側で削除された予定も、取得済みのローカル記録を残す動作があります。
  4. PC上の保存情報の削除を希望する場合は、下記の問い合わせ先で削除範囲を確認し、利用者本人の明示指示に基づく管理操作で、対象ファイルとバックアップを含めて対応します。通常画面に、保存済みの記録とバックアップを一括して消去する機能はありません。

アプリ内の記録削除と、Googleカレンダー側の予定削除は別の操作です。現在の閲覧専用連携で、Googleの予定を削除することはありません。

6. セキュリティ対策

Google公式OAuthによる本人同意、state・PKCEと戻り先検証、Windows本人用の認証情報暗号化、ローカルアプリの本人認証、127.0.0.1での待ち受け、変更操作の保護を使用します。認証トークン・シークレット・認証JSONを公開説明サイトへ載せません。PCやWindowsアカウントの安全管理は利用者本人が行います。

7. この公開サイトについて

このサイトにはアプリ本体、ログインフォーム、業務データの入力フォーム、アクセス解析タグ、広告タグを置きません。Googleカレンダーの予定データや認証情報を、このサイトの公開先へアップロードしません。

この説明サイトの公開に使用するGitHub Pagesでは、サイトへのアクセス時にセキュリティ目的でIPアドレスが記録されます。これはGoogleカレンダー連携で取得する業務データとは別です。詳しくはGitHubのプライバシーに関する説明を参照してください。
